# analise-exportacoes-comexstat-powerbi
Dashboard de exportações brasileiras utilizando dados do COMEXSTAT tratados em Python e visualizados no Power BI.

## Objetivo
Projeto desenvolvido para análise de dados de exportação utilizando Python e Power BI.

## Ferramentas utilizadas
- Python
- Pandas
- Power BI
- Excel
- COMEXSTAT

## Etapas do projeto
1. Extração dos dados
2. Tratamento e limpeza
3. Estruturação em tabelas
4. Criação de dashboards
5. Análise de indicadores

## Resultados
Dashboard interativo para análise de exportações por município, produto e período.
